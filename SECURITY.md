# Security Policy

Central Command is a hosted, remote MCP service. This repository contains **interface documentation only** — no server source, credentials, or user data.

## Reporting a vulnerability

Please report suspected security issues privately to **support@centralcommand.io**. Do not open public issues for security reports. We aim to acknowledge within 72 hours.

## Scope

- The remote MCP endpoint and x402 payment gateway
- Interface/metadata in this repository

Please do not attempt to access other users' data, disrupt the service, or test payment flows with real funds beyond the minimum required to demonstrate an issue.
